# 88 Keys — storefront concept

An independent portfolio concept for a digital-piano storefront. It demonstrates a product catalog, filters, comparison, a guided product finder, a room-fit diagram, a simulated cart, and browser-generated audio.

**Demo only:** this is not an official Roland store and is not affiliated with or endorsed by Roland Corporation. Prices, product details, promotional copy and images are sample material. The site does not accept orders, payments, emails or contact details. The audio preview is synthesized in the browser, not an official product recording.

## Run locally

```sh
npm ci
npm run dev
```

## Build

```sh
npm run typecheck
npm run build
```

Vite writes the static site to `dist/`. Before adapting this concept for a real seller, verify product specifications, prices, image-use rights, stock, shipping, financing, warranty and all store policies.
